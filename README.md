# Course-4-End-of-Course Project: Regression Modeling & Machine Learning Workflows

This repository contains hands-on Jupyter notebooks and datasets focusing on exploratory data analysis (EDA), hypothesis testing, regression modeling, and classification pipelines implemented in Python as part of advanced data science coursework.

## 📂 Repository Contents

### **1. Jupyter Notebooks**
* [`Activity_ Course 5 Automatidata project lab.ipynb`](https://github.com/dyyland23-glitch/Course-4-End-of-course-project-Build-a-multiple-linear-regression-model/blob/main/Activity_%20Course%205%20Automatidata%20project%20lab.ipynb): Practical project lab applying regression modeling, data cleaning, and exploratory data analysis to transportation datasets.
